# 強化購入パネル（#121）

## 採用仕様

初期所持金$30、1回$1、中央1ライン、配当$3/$6/$30の基礎実装に追加。
チェリー6枚追加と7を1枚追加を、商品ごとに$5→$10→$15、最大3回購入できる。
購入はプレイヤーのみ。全購入費は勝敗判定・回転に使う所持金から支払い、再戦でリセットする。
両商品を最大まで買った場合のリールはチェリー22・ベル3・7が5枚。
20/40秒の選択やライバルの自動強化は使用しない。BET額・ライン選択は基礎実装にまだ存在せず、本変更でも追加しない。

## 確認記録

- ローカルChromeで常設パネルの配置、チェリー購入で$30→$25、次価格$10、10枚・1/3表示を確認。
- 回転中の7購入後、購入費と回転費を差し引き、停止時の配当を加えた残高を確認。
- 60秒終了後は購入無効。結果と再戦で$30、4/2枚、0/3、各$5へ復帰。
- 別試合でチェリー3回購入、22枚・3/3とMAX表示、22回転の終盤まで試遊。購入費が残るため必勝ではなく、この試合は敗北。
- 全既存テストと購入のドメインテスト成功。追加の残高表示・再戦・サーバー二重送信・復旧テストも成功。
- 型検査、本番ビルド、lint、生成済みNode ESM起動確認成功。
- 実AI音声接続・公開デプロイは今回の確認対象に含めていない。サーバー試験は音声プロバイダーを代替。

試遊数は少なく、価格の最終的なバランス評価には継続試遊が必要。
