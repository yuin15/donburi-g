# Slot-chanの現在地

2026-09-12。無料の60秒CPUスロット対戦が公開済み。**PC専用、横画面1280×720以上、マウス・キーボード**を対象にする。音声・映像は任意で、APIキー、招待、マイク、Upstashなしに遊べる。

## ゲームと画面

- #64で手動回転に変更。クリック・Spaceで両者1回転、回転中の連打は次の1回だけ予約。無入力では回らず、60秒以内に実際に受け付けた回転数で競う。間隔1.1秒以上、最大55回、結果に実回転数を表示する。
- 中央1ライン、配当120/240/1200、20秒・40秒に2択改造、勝利・敗北・引き分け、再戦まで実装。選択は24秒・44秒の期限で確定し、遅れた入力や二重入力で延長しない。改造パネルを右へ移し、選択中も回すボタンを操作できる。
- #46で改造5秒前のプレビュー、現在→改造後の当たり率/7揃い率、未選択時の適用通知を追加。公開Chromeの60秒対戦で確認済み。
- #50/#51で両者の出目に合うCPU台詞と表情、結果の配当内訳・改造順・最高の一回を追加。確定集計をsnapshotに含め、描画の欠落から回復しても全回転の集計を保持する。
- #63で改造構成と同じ枚数の絵柄を表示し、相手の小リールも実際に下向きに回転させた。両者の構成バーに絵柄数を表示する。
- #68で相手の当たりに青い小リール発光・加点・効果音を追加。連打中も両加点と自分の金貨を短い表示寿命まで残す。相手の改造中・確定後の追加絵柄を、台詞に消されない構成バー上で知らせる。
- #70で改造開始時の自動フォーカスを削除。Space連打が安定型の誤選択へ切り替わらず、クリック・1/2キー・Tabで選べる。
- #60で勝敗別の色と大きなコイン表示、点差、開閉する内訳、勝利の金貨演出を追加。改造カードは色・大きいキー・残り時間バー・選択済みマークで見分けられる。
- #52でLive字幕を定型文による上書きから保護し、再戦準備の得点・時間・内訳を初期化。実APIを使用しないDEV表示順の検収を記録した。
- #58で試合終了時にマイクを停止し、旧音声・旧字幕を接続世代で遮断。結果専用GPTは旧接続のcloseとLiveAvatarの音声消去確認後に1回だけ開始する。失敗しても確定結果を残す。
- 参考画像を基に筐体・操作台・専用絵柄・架空の成人ライバル4表情を制作。1つのThree.js描画へ集約し、HTMLで文字・操作を重ねる。
- リールは同じ絵柄が上から下へ連続して流れ、左→中→右に停止。両得点・台詞・結果は確定した停止フレームの後に更新する。相手の小リールは正方形の絵柄を保ち、縦潰れを修正した。
- #43でスマホ用の縦配置・縮小UI・背景切り出しを削除。狭いウィンドウは最小幅1280pxと横スクロールでPC構図を維持する。スマホ用UI・タッチ最適化は対象外。
- 静止/非表示では連続描画せず、素材4点・概算20.4MiB。任意LiveClient/LiveKitはCPU入口で読み込まない。相手の当たり表示を加えた主JSは138.00KB gzip、CSSは5.48KB gzip。

## 確認した範囲

- 型検査、lint、208テスト、生成済みNode ESMの起動と拒否応答、本番ビルドが成功。実localhost WebSocket＋MatchSession結合2ケースは手動spin要求で確認した。認証・利用枠・外部プロバイダーは代替。500KB超のビルド警告は残る。
- 公開Chromeの手動対戦は32回転で840対1,080。無操作0回、連打予約、改造、60秒の最終停止待ち、結果、再戦後0回への初期化を確認した。旧自動版では25秒のページ停止から30回転の結果へ復旧、カウントダウン取消、効果音ミュートも確認済み。
- PCの1280×720 / 1920×1080を目視。通常・小当たり・7揃い・逆転・同点・最終スピンはDEV専用の検収画面でも確認し、回転動画と連続フレームを記録した。固定出目は本番に含まれない。
- 改造リールの録画時は406標本、中央値16.7ms、p95 16.8ms、最大33描画・252三角形。高性能PC上の測定であり、全端末の性能保証ではない。
- 公開CPU入口の通信は外部/API要求なし、初期約0.684MB（PR #41観測）。任意Live無効時のHTTP 401 / WebSocket拒否1008を、PR #42の公開版でも確認した。
- 個人メール・実会話を記録しない。秘密値はGit対象外のローカル環境とVercelのサーバーSecretsで管理し、追跡ファイル・ビルド・コミット差分を検査する。

詳細: [相手の当たり・連打中の加点](rival-feedback.md)、[手動回転の操作・公開確認](manual-spin.md)、[改造リールの表示](visible-upgrades.md)、[勝敗・改造の見栄え改善](duel-polish-verification.md)、[通信・期限の検証](live-sync-verification.md)、[ゲーム規則](game-rules.md)。[バランス測定](game-balance.md)は旧自動30回転の測定、[旧完了監査](completion-audit.md)はPR #34時点の履歴。
