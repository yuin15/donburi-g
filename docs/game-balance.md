# デモのバランス確認（2026-09-12）

`npm run analyze:balance` で再現できます。共通の10,000 seedを各対戦に使い、プレイヤー／ライバルの席を交換した計20,000試合で集計しています。実APIを使わないルールのシミュレーションです。勝率の分母には引き分けも含みます。

以前の「チェリー2枚追加／7を2枚追加」では、安定型を2回選ぶ戦略の勝率は大勝負2回に対して24.665%でした。得点平均も991.68対2,095.09で大きく偏っていました。

配当と60秒の進行は維持し、安定型をチェリー6枚、大勝負を7が1枚の追加へ変更しました。サーバーと練習モードは同じ定義を使用し、UIの説明もそこから生成します。

| 2回の選択 | 得点平均 | 中央値 | 下位10%点 | 上位10%点 |
| --- | ---: | ---: | ---: | ---: |
| 安定→安定 | 1,233.63 | 1,080 | 720 | 2,160 |
| 安定→大勝負 | 1,104.64 | 960 | 480 | 2,040 |
| 大勝負→安定 | 1,178.93 | 840 | 360 | 2,280 |
| 大勝負→大勝負 | 1,424.32 | 1,440 | 240 | 2,880 |

安定2回と大勝負2回の直接対戦は、安定の勝ち46.840%、大勝負の勝ち49.950%、引き分け3.210%です。安定型は低得点になりにくく、大勝負は得点の振れ幅が大きくなります。残り10秒で負けていた側が勝つ割合は、安定側2.605%、大勝負側8.590%でした（いずれも全20,000試合が分母）。接戦や逆転を保証する出目操作は行いません。

混合戦略の勝率は相手によって36.56〜49.375%で、途中の方針変更が常に有利なわけではありません。得点差を見て選ぶ人間の戦略や会話の楽しさは、この固定戦略の集計だけでは判断できません。実際の初見プレイで引き続き確認します。

勝利・敗北・引き分け・残り10秒からの逆転を再現するseedと入力は `src/domain/game.test.ts` にあります。固定seedはテスト専用で、ライブのランダム生成には使用しません。
