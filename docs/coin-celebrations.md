# 当たりと勝利の3Dコイン演出

既存のHoudini製コイン・金属材質を流用し、当たりでは噴射から残高への回収、対戦勝利では噴き上げから金の雨へつながる演出を追加した。抽選、BET、配当、残高、60秒の時計、回転受付の規則は変更していない。

## プレイヤーが見る流れ

| 場面 | コイン | 演出時間 | 音 |
| --- | --- | --- | --- |
| チェリー | 24枚が跳ねて残高へ移動 | 650ms | 短い衝撃音と回収音 |
| ベル | 72枚が扇状に広がり回収 | 900ms | 金属音を重ねた払い出し |
| 7・大当たり | 手前270枚を時間差で噴射。背景に600枚の金の雨 | 手前1700ms、背景3000ms | 低音、上昇音、複数回のコイン音 |
| 対戦勝利 | 手前480枚（噴き上げ180枚＋金の雨300枚）、背景600枚 | 3000ms | 勝利専用ファンファーレ |

相手の当たりは12／27／54枚で、顔と字幕の外側から相手の残高へ回収する。勝利時だけ結果画面の両者の金額を1800msでカウントアップし、確定値に到達する。画面上部の残高・勝者・記録は確定値を表示し、カウント途中の値をゲームの計算に戻さない。敗北と引き分けはそれぞれ短い専用音で区別する。

初版からプレイヤーの当たりを4〜5倍、勝利を5倍に増量。発射の時差・横の広がり・到達する高さを独立してばらし、同じ軌道に重なって枚数が少なく見えることを避けた。勝利のコインは上部の残高・タイマーと結果金額の外側へ噴き上げる。

プレイヤーの大当たり・勝利には、画面全体を覆う背景のコイン雨を追加。600枚の再利用枠で回転しながら上から下へ降らせ、筐体・リール・相手の顔・得点より奥に描画する。雨は3秒間続いてフェードアウトし、大当たりの回収終了や次の回転でも途切れない。連続大当たりでは同じ枠の3秒を更新し、描画枚数を無制限に増やさない。相手だけの大当たり・敗北・引き分けでは背景の雨を出さない。

次の回転を待たせず、前の払い出しと次の払い出しを各側2枠まで重ねて再生する。結果・再戦・退出では前の演出を終了する。非表示タブでは描画を止め、古い演出を再生し直さない。動きを減らす設定では飛ぶコインを省き、結果金額を即時表示する。

## 案の比較と採用理由

開発用 `?visual-review` の「コイン比較」で、A「噴水から回収」とB「金の雨から回収」を同じ7当たりの局面で比較できる。1280×720で比較し、噴射の出発点と残高への移動が分かりやすく、揃った7を読み取りやすいAを本番の既定にした。金の雨は対戦勝利の後半へ採用した。比較操作は本番画面には表示しない。

「小当たり」「ベル／チェリー」「両者7揃い」「自己ベスト・3連勝」「最終スピン」「敗北」「引き分け」で各局面を表示できる。これらは開発用の固定局面で、通常抽選の結果ではない。「録画なしでFPS計測」「勝利3秒を計測」「待機5秒を計測」は実行環境での再計測に使う。録画は筐体とコインの両キャンバスを合成する。DOMの金額・字幕と音声は録画に含めない。

## 主な作業対象

- `src/view/CoinCelebration.ts`：手前5枠＋背景1枠の再利用枠、噴射・回収・勝利・背景の雨の軌道。
- `src/view/CabinetArt.ts` / `ReelScene.ts`：筐体の光・当たり・勝利とコインの開始／終了を連動。
- `src/view/GameAudio.ts`：チェリー・ベル・大当たり・勝敗ごとの合成効果音。
- `src/view/GameView.ts` / `ResultCountUp.ts`：勝利時の金額表示と中断・再戦時の後片付け。
- `src/viewmodel/RewardPresentation.ts` / `GameViewModel.ts`：表示時間と音の選択。ゲーム規則・通信形式は変更しない。
- `src/view/VisualReview.ts` / `src/dev/GameReview.ts`：同一画面での案の比較と計測。

## 検証

確認用サイトは `npm run build:review` で生成する `review-dist/` を静的ホストへ配置する。通常の `npm run build` には検収ツールを含めない。

- `/?visual-review&example=final`：最後の7スピンから勝利まで動的に再生。
- `/?visual-review&example=jackpot`：7当たりを静止表示して形と配置を比較。
- `/?visual-review`：「録画なしでFPS計測」で当たりを順番に再生、「勝利3秒を計測」で勝利を再生する。クリックすると効果音も有効になる。
- `/`：通常のCPU対戦。確認用の静的サイトでは外部AI音声は利用できない。

- 背景の雨追加と最新main取り込み後、全31ファイル・565テスト成功。背景の描画レイヤー、3秒の終了、連続大当たりでの時間更新、次の回転でも継続すること、静止比較・動きを減らす設定を既存テストで確認。
- TypeScript、ESLint、サーバー起動確認、本番ビルド、差分の空白検査を通過。
- 通常の無料CPU対戦を60秒プレイし、連打しても1回転のみ、相手30回転、確定結果、再戦で初期残高へ戻ること、退出を確認。ブラウザーエラーなし。
- 勝利の金額表示と3Dコインは開発用の固定局面で確認。通常対戦で勝利を引いた検証とは区別する。
- 外部AI音声サービスへの接続、効果音の聴感調整、別PC・別ブラウザーでの実測は未実施。
