# ライバルの表情差分

2026-09-14。元の通常表情と、Vercel AI Gateway の `openai/gpt-image-2.5-sunburst` で生成した17枚を組み込んだ。生成元は `3ba542614bb722918191092a24ea049ece930ed4` の `public/art/rival-expressions.webp` 左上。架空の成人女性の顔・髪・衣装・背景を保ち、表情だけを変更する指示を使っている。

## 素材と表示

- `public/art/rival-expressions-expanded.webp`：通常1枚＋生成17枚、3列×6段。元の4表情画像は制作履歴として残す。
- 各肖像は512×384。上下左右4pxに端の画素を複製し、隣の表情が縁へ混ざらないようにした。
- 全体は1560×2352、517,576 bytes。ゲーム中はこの1枚だけを読み込み、画像生成APIへの接続は不要。
- `src/viewmodel/RivalExpressions.ts` が並び順と画像寸法を定義する。左から右、上から下へ、下表の順に並ぶ。
- `ReelScene` は肖像の内側を切り出す。元の反応時ズームと軽減モーション設定を引き継ぐ。

## 確認方法

通常のCPU対戦で自動切り替えを確認できる。開発サーバーの `/?visual-review` には既存の検収ツールがあり、「表情確認」で18表情を個別に表示できる。既存の大当たり・残り8秒・選択肢・注意逸らしの固定表示にも同じ表情判断を適用する。この検収ツールは通常の本番ビルドには含まれない。

型チェック、lint、既存610テスト、サーバー起動チェック、本番ビルドを実施済み。1280×720のブラウザー画面で切り出し・当たり・終盤・会話状態を確認。実際のLive音声接続は未実施。
