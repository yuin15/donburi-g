# 改造を反映するリール表示

Issue #63 の実装。基本リールと確定済み改造から表示用の絵柄列を作り、Three.jsで両者のリールを下向きに回転させる。安定型はチェリー、大勝負は7の表示枚数も増える。抽選・配当はゲーム本体の確定値を使う。

表示用の並びは同じ絵柄が固まりすぎないよう配置する。回転途中の改造通知は次の回転まで保持し、中央の確定絵柄を維持して切り替える。相手の小リールも820/940/1060msの順に止まり、縦横比を保つ。

自分と相手の構成バーに絵柄の枚数を表示する。初期構成は4/3/2、安定型2回は16/3/2、大勝負2回は4/3/4。色に加え絵柄と枚数、読み上げ用説明を付ける。

ローカルChromeの固定場面で安定型2回と大勝負2回の表示、中央の指定絵柄への停止を確認した。録画時のp95フレーム間隔は16.8ms、テクスチャは4枚。これは当該PCでの計測であり、全PCの性能を保証する値ではない。
