# 画面いっぱいに登場する勝利文字

対戦勝利の「YOU WIN!」を、左の筐体から画面中央へ広げる。金色の立体文字が画面幅の約90%まで弾み、放射状の光・既存のコイン雨・既存のファンファーレと一緒に表示される。既存の3秒間の最後で元の見出し位置へ収まり、結果金額・ROUND STATS・REMATCHを読める状態に戻る。

## 作業対象

- `src/view/VictoryTitle.ts`：勝利文字の大きさ・飛び出し・放射光・結果位置への移動。YOU WIN専用の金属色・反射の帯・星形のきらめきを描画する。
- `src/view/SculptedType.ts`：面取りの幅を指定できるようにする。指定しない既存文字は従来どおり。
- `src/view/CabinetArt.ts`：既存の勝利タイミングに接続し、結果変更・停止・動きを減らす設定で解除する。
- `src/view/ReelScene.ts` / `PhysicalPresentation.css`：演出中だけ結果パネルより前に描画する。マウス操作は遮らない。
- `src/view/ReelScene.test.ts`：既存の勝利テストで前面表示・3秒後の復帰・動きを減らす設定・停止時の解除を確認する。テスト件数は増やしていない。

ゲーム規則、配当、残高、勝敗、入力受付、敗北・引き分け、コイン数、効果音は変更しない。独自のタイマーや継続描画は追加せず、既存の描画ループを使う。

## 拡大演出の確認方法と結果

開発サーバーまたは確認用ビルドの `/?visual-review&example=session-best` で勝利を再生する。「自己ベスト・3連勝」で繰り返せる。Escで確認ツールを隠せる。固定場面による表示確認であり、通常抽選とは区別する。

- 1280×720・1920×1080のブラウザーで、文字全体の収まり、コインと光、3秒後の結果表示を確認。
- 敗北の通常表示をブラウザーで確認。引き分け・動きを減らす設定・停止時の解除は自動テストで確認。
- 通常のCPU対戦を60秒完走し、プレイヤー$30・相手$0の勝利結果とROUND STATSを確認。REMATCHで両者$30・1:00へ戻り、結果・内訳・前面演出が解除された。
- 31ファイル・565テスト成功。既存勝利テストを更新後、描画の24テストを再実行して成功。
- TypeScript、ESLint、サーバー実行形式の起動確認、本番・確認用ビルド成功。既存の大きいチャンクと依存パッケージの注釈警告は残る。
- Windowsの設定読込時の権限制約により、テストとビルドはAPIルートを含まない一時設定を`--configLoader native`で読み込んだ。リポジトリのVite設定は変更していない。

公開サイトへの反映、外部AI音声・映像への接続、別PCでの確認、効果音の聴感評価は実施対象外。

## 追加の光沢調整

金の明暗がはっきりした反射模様、従来の約2.7倍の幅の金の面取り、文字を横切る白い光、文字の形状に沿った12個の星形の輝きを追加した。縮小後のYOU WINにも金属色を残し、3秒後には光の移動と点滅を止める。勝利以外の文字の材質は変更しない。専用材質ときらめきだけを解放し、共有の文字形状・環境画像を二重に解放しない。

光沢追加後も565テスト、TypeScript、ESLint、サーバー起動確認、本番・確認用ビルドが成功。最終の光沢表示はユーザーがローカルプレビューで確認済み。上記2画面サイズの目視確認と通常対戦の記録は、光沢追加前の拡大演出に対するもの。
