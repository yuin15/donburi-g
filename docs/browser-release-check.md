## キーボード導線の修正（Issue #33）

公開版で入口を開きTabを押すと、背面の効果音ボタンにフォーカスする不具合を実Chromeで再現した。入口表示中のゲーム画面を `inert` にし、入口を名前付きダイアログとして示す。改造表示時は最初の選択肢へ移動し、確定後は選択済みの説明をフォーカスする。閉じる際は直前の使用可能な操作へ戻す。

修正版のローカル実Chromeで次をUI操作とDOM観測で確認した。ゲーム状態やフォーカスへの検証用スクリプト注入は行っていない。

- 最初のTabはCPU開始ボタン。Enterで開始すると背景のinertが解除され、カウントダウン中の退出を操作できる。
- 20秒の改造で安定型ボタンにフォーカス。数字キー2で大勝負を確定し、両選択肢が無効になり、選択済み説明へフォーカスする。
- 改造終了後は直前の退出ボタンへ復帰。Enterで入口へ戻るとCPU開始ボタンにフォーカスし、背景は再びinertになる。
- 入口で次のTabは任意の音声・映像の開閉へ移動する。
