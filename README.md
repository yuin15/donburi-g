# donburi-g

Game jam project by team **donburi**.

## Security rule

This repository is public. **Never commit API keys, access tokens, passwords, private keys, service-account credentials, or other secrets.**

- Keep local secrets in `.env` or `.dev.vars` only.
- Commit only placeholder examples such as `.env.example`.
- Use the hosting provider's secret/environment-variable store for deployed environments.
- If a secret is committed accidentally, revoke/rotate it immediately; deleting the file from a later commit is not sufficient.

See [`SECURITY.md`](./SECURITY.md) before adding any external API.
