# Issue #117 進捗

## 完了

- 音声字幕の日本語・英語の時間延長依頼を、残り15秒以下かつ1試合1回に限定して検出するようにした。
- Responses の判定には残時間、両者の残高、当該発話、直前会話を渡し、厳密な `accept_extension_10s` / `reject_extension` 以外と失敗・タイムアウトは拒否にした。
- 延長はドメインの一度だけ許可される +10 秒処理から反映し、60秒から70秒までの残時間、回転上限、wire検証、結果条件を整合させた。
- 判定中は通常のLive音声・字幕を遮断し、旧返答の無音境界または4秒上限後に既存の commentary 経路で確定台詞を発話するようにした。
- VM/View/CSS/GameAudio に `RULE CHANGED`、`+10 SEC`、延長前後の時刻表示、専用SEを追加し、開発用表示検収に受諾・拒否fixtureを加えた。
- `npm test`（288件）、`npm run typecheck`、`npm run lint`、`npm run check:server-runtime`、`npm run build` を実行した。
- Review #124 の修正として、発話途中の字幕デルタでは交渉を始めず、発話終了後に300msの字幕安定待ちを置いた。否定と残り時間の説明も依頼から除外した。
- 同一バッチ確認の追加修正として、15秒より前に終わった発話は、遅延字幕が届いても交渉待機・通常音声抑制を開始しないようにした。
